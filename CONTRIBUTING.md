# Contributing

Issues and pull requests are welcome. Fork the repository, make a focused change,
run `node --test`, and explain the problem, result and checks. Include a synthetic
example for diagram changes and inspect it on a white background. Keep documentation
in English. Do not contribute secrets or proprietary project data.

The project owner, **@blabbler78**, is the sole maintainer and code owner. External
contributors do not receive write, merge or administrative access. Only the owner
accepts changes and manages releases. Branch rules require owner review for outside
changes; the owner retains administrative control for maintenance. Reviews from
other users are welcome feedback but do not authorize a merge. Do not add autonomous
merge bots or grant other users privileged access without the owner's decision.

By submitting a contribution you confirm that you have the right to submit it
under this repository's MIT license. Retain required third-party notices. This does
not transfer your copyright to the maintainer. MIT permits independent forks;
the owner's approval controls this repository, not other people's forks.
